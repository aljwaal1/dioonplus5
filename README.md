# Dioon Plus

هذا المستودع هو المصدر الرسمي لتطبيق **Dioon Plus**.

## النسخة الحالية
- Version name: `0.5.6`
- Version code: `15`
- Package: `com.dioonplus.app`

## قاعدة التطوير
- الفرع الرسمي الوحيد المعتمد للتطوير والإصدارات هو `main`.
- أي فرع تشخيصي أو تجريبي قديم لا يُعد مصدرًا صالحًا للإصدار.
- أي إصدار جديد يجب أن يبدأ من أحدث `main` فقط.

## Google Play / AdMob
- إعدادات الإصدار الرسمية موجودة في `main`.
- لا تستخدم أي قيم AdMob أو إعدادات مأخوذة من فروع التشخيص القديمة.
