# ديون بلس

تطبيق أندرويد عربي فردي لإدارة ديون العملاء والموردين، يعمل محلياً ولا يشترط التسجيل برقم هاتف أو رمز SMS.

## المرحلة الحالية

تم إنشاء الأساس البصري الأول للتطبيق باستخدام Kotlin وJetpack Compose وMaterial 3، ويشمل:

- واجهة عربية RTL.
- الصفحة الرئيسية وقائمة العملاء والموردين.
- ملخص الأرصدة بألوان مالية واضحة.
- شاشة تقارير احترافية مع رسم مبسط.
- معاينة أولية لتقرير PDF.
- شاشة إعدادات للأمان والاسترداد والنسخ الاحتياطي.

البيانات المعروضة حالياً تجريبية بهدف تثبيت التصميم وتجربة الاستخدام قبل ربط قاعدة البيانات.

## التشغيل

1. افتح المشروع في إصدار حديث من Android Studio.
2. استخدم JDK 17.
3. ثبّت Android SDK 36 وcompile SDK 37.
4. نفّذ Gradle Sync ثم شغّل التطبيق على محاكي أو هاتف Android.

## القرارات الأساسية

- النظام فردي لمستخدم واحد.
- لا يوجد تسجيل إلزامي برقم الهاتف.
- الدخول سيكون بكلمة مرور أو PIN.
- بريد الاسترداد اختياري.
- التطبيق مصمم للعمل دون إنترنت.

راجع [نظام التصميم](docs/DESIGN_SYSTEM_AR.md) للتفاصيل البصرية.
